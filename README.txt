GHSS Naseer Killi Public Portal PWA

Upload all files in this folder to the ROOT of your GitHub repository, replacing existing files with the same names.
Files: index.html, manifest.json, service-worker.js, icon-192.png, icon-512.png, .nojekyll
Then open Repository Settings > Pages > Deploy from a branch > main > /(root).
Android: open the published HTTPS site in Chrome and choose Install app.
iPhone: open the published HTTPS site in Safari > Share > Add to Home Screen.
The Public Portal button opens the supplied Google Apps Script URL. Portal data/login still require internet.
